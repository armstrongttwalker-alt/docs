# 模型管理

模型管理页面用于管理平台模型（管理端功能）。

## 访问路径

左侧导航栏 → **管理端** → **模型管理**

## 列表字段

| 列名 | 说明 |
|------|------|
| 模型名称 | 模型名称（最多 128 字符） |
| 模型描述 | 模型描述（最多 256 字符） |
| 模型原始路径 | 支持 ModelScope 和 Huggingface |
| 状态 | 模型状态 |
| 创建时间 | 模型创建时间 |

## 模型状态

| 状态 | 说明 |
|------|------|
| 初始化 | 模型正在初始化 |
| 保存中 | 模型正在保存 |
| 成功 | 模型创建成功 |
| 失败 | 模型创建失败 |

```{note}
只有终态（成功、失败）的模型可以删除。
```

## 新建模型

点击 **新建模型** 按钮，填写表单信息：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 模型名称 | 文本框 | 是 | 最多 128 字符 |
| 模型描述 | 文本域 | 否 | 最多 256 字符 |
| 模型原始路径 | 文本框 | 是 | 支持 ModelScope 和 Huggingface |

## 删除模型

点击模型行的 **删除** 按钮，删除模型。

```{warning}
暂时只删除数据库，文件实际底层当前因实现限制不支持删除，后续会迭代支持。
```
