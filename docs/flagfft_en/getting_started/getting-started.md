# Getting Started with FlagFFT

## Requirements

### Hardware

- NVIDIA GPU with CUDA support.

### Software

- CUDA Toolkit
- Python 3.10+ with development files
- PyTorch
- CMake and Ninja
- SQLite3
- pybind11

### JIT Generation Environment

For runtime JIT kernel generation:

- Triton/TLE-enabled Python environment
- `pytest` (for running tests)
