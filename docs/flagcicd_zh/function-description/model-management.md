# 模型管理

模型管理功能支持平台托管 AI 模型，管理端可创建和管理模型，用户端可查看已成功的模型列表。

## 概述

模型管理模块支持从 ModelScope 和 Huggingface 导入模型，为 CI/CD 流程提供模型挂载能力。

## 管理端功能

管理端可创建、查看和删除模型。

| 字段 | 说明 |
|------|------|
| 模型名称 | 必输，最多 128 字符 |
| 模型描述 | 最多 256 字符 |
| 模型原始路径 | 支持 ModelScope 和 Huggingface |
| 状态 | 初始化、保存中、成功、失败 |

```{note}
只有终态（成功、失败）的模型可以删除。
```

## 用户端功能

用户端模型中心只显示状态为成功的模型，按创建时间倒序排列。

```{warning}
模型删除暂时只删除数据库，文件实际底层当前因实现限制不支持删除，后续会迭代支持。
```
