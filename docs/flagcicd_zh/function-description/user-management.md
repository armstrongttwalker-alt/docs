# 用户管理

用户管理功能提供角色权限体系，支持 {term}`平台管理员`、{term}`特权用户` 和 {term}`普通用户` 三种角色，实现对平台功能的分级访问控制。

## 概述

FlagCICD 采用基于角色的访问控制（RBAC），通过角色类型和用户状态管理用户权限。

## 角色类型

| 角色 | 权限说明 |
|------|----------|
| {term}`平台管理员` | 用户端及管理端所有权限，包含特权用户 |
| {term}`特权用户` | 新建 runner（DooD 和 DinD 选型可见） |
| {term}`普通用户` | 用户端所有菜单 |

## 用户状态

| 状态 | 说明 |
|------|------|
| 正常 | 可正常使用平台 |
| 禁用 | 无法登录平台 |
